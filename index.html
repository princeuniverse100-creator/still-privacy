1. Who operates Still

Still is operated by Prince . Privacy questions can be sent to forequest.in@gmail.com.

2. Information processed on your device

Still stores the selected session duration, session end time, onboarding completion, and permission state locally. During an active session, Usage Access may provide the package name and usage timestamp of the currently used app. The Accessibility service may observe app-window changes and package names so Still can detect when another app opens and return the user to the focus screen.

Still is designed not to read or record typed text, passwords, message content, screen content, contacts, call logs, photos, files, microphone input, camera input, or precise location.

3. How information is used

Local information is used only to run the selected timer, remember completed setup, display the focus interface, identify an app opened during a session, and apply the focus behavior chosen by the user.

4. Collection and sharing

Still has no account, advertising, analytics, cloud storage, or remote server. Information described above is processed locally and is not sold, shared with third parties, or transmitted off the device.

5. Permission-specific behavior

  • Usage Access: identifies the currently used app and related timestamps during an active focus session.
  • Accessibility: observes app changes for the focus-session behavior. It is not represented as an accessibility tool for people with disabilities.

Still does not request Display Over Other Apps, Device Administrator, direct battery-optimization exemption, notification permission, or broad package visibility.

6. Retention and deletion

Session state is retained only as needed to operate the active timer. Preferences remain until changed, app storage is cleared, or Still is uninstalled. Clearing app storage or uninstalling the app removes locally saved information.

7. Security

Keeping information on the device limits external exposure. Android controls access to app storage and permission settings. No method of storage is completely risk-free.

8. Children

Still is a general-audience productivity app and is not directed to children under 13.

9. Changes

This policy will be updated before features that change data handling—such as accounts, payments, analytics, or cloud synchronization—are released. The effective date will change when the policy changes.
